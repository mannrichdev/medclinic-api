# MedClinic API 🏥

API RESTful desenvolvida em Node.js e TypeScript para gerenciamento de clínicas médicas, cadastro de pacientes e agendamento de consultas.

## 🛠️ Tecnologias Utilizadas
- **Linguagem/Runtime:** Node.js, TypeScript (`tsx`)
- **Framework Web:** Express
- **ORM & Banco de Dados:** TypeORM, PostgreSQL
- **Segurança:** JWT (JSON Web Token), BcryptJS
- **Documentação:** Swagger UI
