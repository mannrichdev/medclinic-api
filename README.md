# 🏥 MedClinic API

API RESTful desenvolvida em Node.js e TypeScript para gerenciamento de clínica médica, com autenticação JWT, controle de acesso baseado em funções (RBAC) e documentação via Swagger UI.

---

## 🛠️ Tecnologias Utilizadas

* **Linguagem & Framework:** Node.js, Express, TypeScript
* **Banco de Dados & ORM:** PostgreSQL, TypeORM
* **Segurança:** JWT (JSON Web Token), BcryptJS
* **Documentação:** Swagger UI
